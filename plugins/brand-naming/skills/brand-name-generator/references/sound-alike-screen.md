# Pronunciation & Sound-Alike Screen

A name lives in the **ear**, not just on the page. It is said at a party, on a
podcast, into a voice assistant, mispronounced by a stranger, and slurred when said
fast. Word-of-mouth — the engine of a name going viral — runs entirely on *sound*.
So a name must be screened for what it **sounds like**, not only how it is spelled.

The trap this screen exists to catch: a name that *reads* clean and distinctive but,
**spoken aloud, collapses into a negative or embarrassing word**.

- **Engree** → sounds like **angry**.
- **Keel** → sounds like **kill**.
- **Faylo** → sounds like **fail**. · **Sikoda** → opens on **sick**. · **Mortis** → **mortify / death**.

Good spelling can never rescue a name that *sounds* wrong. This is separate from —
and runs **alongside** — the visual-ambiguity check (`rn`↔`m`, `cl`↔`d`); that one
guards the eye, this one guards the ear. Both are knockouts.

---

## The say-it-aloud test (run on every candidate)

1. **Say it three ways:** (a) carefully, (b) fast / slurred / mid-sentence,
   (c) in the target-market accent(s). Fast and slurred is where bad words surface.
2. **Cold read:** have someone who has **never seen it spelled** hear it once and
   say it back, then spell it. If the *heard* version drifts from the *intended*
   version — or anyone smirks — that is a flag.
3. **Read the run-together form** (the lowercased domain/handle/slug, no spaces).
4. **Check the five-language sound** (Spanish, Mandarin, Arabic, Japanese, German):
   does the *sound* map onto a vulgar/negative word there? (Pajero, Pinto.)

Verdict:
- **Knockout (near-veto):** the sound-alike is a clearly negative, vulgar, or taboo
  word in a target market. Treat like a SCRATCH spelling failure — cut it, no matter
  how high it scored elsewhere.
- **Flag → native-speaker review:** borderline, region-specific, or accent-dependent.
  AI pre-screens; it does **not** replace an in-country native speaker.

## Stop-words — sound-alike categories to screen against

Reject (or flag) a candidate that *sounds like*, opens on, or embeds any of these.
This list is a starting set — **extend it per brief** with the slurs, competitor
names, and loaded terms specific to the category and target markets.

| Category | Watch for the *sound* of… |
|---|---|
| **Anger / aggression** | angry, mad, rage, hate, kill, fight, war, attack, harm |
| **Death / harm** | kill, die, dead, death, mortis, slay, doom, croak, grave, fatal |
| **Illness / pain** | sick, ill, ail, ache, sore, pain, hurt, virus, plague, nausea |
| **Failure / loss** | fail, flop, lose, loss, broke, bust, dud, flunk, ruin, debt |
| **Fear / negativity** | fear, dread, fright, scare, panic, gloom, dire, grim |
| **Profanity / vulgar** | embedded f‑, sh‑, a‑s, d‑mn, b‑tch, c‑nt and their near-misses (sheet→…, fokus→…, beach→…) |
| **Bodily / scatological** | pee, poo, fart, gas, butt, crap, snot, puke, barf, turd |
| **Slurs / sensitive-group terms** | any racial, ethnic, gender, or disability slur or near-homophone — **non-negotiable cut** |
| **Dismissive / dull** | meh, blah, dull, lame, dumb, drab, nope, ugh |
| **Negative particles hiding inside** | mal‑ (bad), mis‑, dis‑, un‑, anti‑, sub‑, ill‑, no‑, low‑, ‑less |

> The two-given anchors: **angry** (so *Engree*, *Angri*, *Ingry* are out) and
> **kill** (so *Keel*, *Kil*, *Killa*, *Kyle*-adjacent coinages get a hard look).

## Sound-pattern red flags (structural)

Beyond the word list, these *patterns* reliably produce trouble:

- **Slur-on-speed-up.** Said quickly, do the syllables merge into a bad word?
  (`Mass Effect` said fast, `An-gree`, `Ass-ets`-adjacent coinages.) Always test the
  fast read.
- **Vowel-flip ambiguity.** A short↔long vowel swap that lands on a negative word:
  **keel/kill**, **sheet/sh‑t**, **beach/b‑tch**, **fox/f‑‑‑s**, **ship/sheep**.
  Front-vowel coinages (the "ee"/"i" sounds) are the most exposed — verify the
  vowel can't be heard the wrong way.
- **Run-together two-word misread.** A two-word name ships as one lowercased token
  and can birth a new, unintended word. Classic disasters:
  *Who Represents → whorepresents*, *Pen Island → penisland*,
  *Experts Exchange → expertsexchange*, *Therapist → the‑rapist*,
  *Speed of Art → speedofart*. **Always read the concatenated slug aloud.**
- **Acronym / initialism hazard.** Does the name — or its natural abbreviation /
  initials — spell or sound like something bad? (A "Total Workflow System" is *TWS*;
  check it.)
- **Cross-language homophone.** Neutral in English, vulgar/negative when *heard* in
  a target language. The five-language sound check above.
- **Hard-to-say onset clusters.** `mn‑`, `ps‑`, `tsq‑`, `vl‑`, consonant pileups —
  these don't sound *negative*, but they fracture word-of-mouth: everyone says them
  differently, so the name never settles into one shareable sound. Penalise on
  Pronounceability.
- **Stress-shift word.** If moving the stress to a different syllable yields a
  different or negative word, the name is unstable across speakers/accents.

## How it slots into the process

- **During generation (Step 4):** say each candidate aloud as you write it; reject
  obvious sound-alikes at birth — don't let them reach the pool.
- **As a knockout (Step 5, filter 1):** the phonetic sound-alike check sits next to
  the visual-ambiguity check. Clear negative/taboo sound = cut.
- **In the linguistic pre-screen (Step 5 / Stage 5):** extend to all target-market
  languages and accents; output a flag per market for native-speaker follow-up.
- **In scoring:** a name that sounds like a negative word is a **near-veto on
  Pronounceability** — do not let a high Memorability or Distinctiveness score
  rescue it (see `scoring-rubric.md` §Scoring discipline).

Remember the limit: this is an **AI pre-screen**. It catches the obvious and the
structural; it misses fresh slang, regional accent quirks, and current events.
Native-speaker review remains required before any international launch.
